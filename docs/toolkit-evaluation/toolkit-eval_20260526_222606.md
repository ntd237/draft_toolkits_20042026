### 12.4 Statement of Limitations

- Đây là **read-only static audit**. Không có file nào trong bundle bị sửa.
- Static analysis thay cho live execution — capability score phản ánh skill content **buộc** assistant phải làm gì, không phải cleverness của assistant cụ thể.
- Token số liệu là **estimated** từ byte length, không phải đo bằng tokenizer thực.
- Audit này phạm vi Claude-Code surface; không chấm `.codex/`, `.cursor-plugin/`, `.opencode/` của các bundle có support đa-platform — chỉ ghi nhận sự tồn tại.
- `jcode` và `hermes-agent` thực chất là application code (Rust/Python) chứa skill phụ — score thấp không phản ánh chất lượng app, chỉ phản ánh fit-for-purpose như Claude Code harness.
- Claude-kit có 174 skills — sample 8–10 skill chính chấm chi tiết, 165+ còn lại đánh giá tổng hợp qua signal (frontmatter density, file size, references count). Không khả thi đọc 100% trong session đơn.
- Hermes-agent có 90+ active skill và 84 optional skill — sample 6–7 skill chủ đạo của software-development category; 165+ còn lại không được chấm cá thể.
